# Painel Administrativo - LB Negócios Imobiliários

Projeto independente para gestão e publicação de imóveis na nuvem do Firebase Firestore.

## 🚀 Como subir este projeto para um NOVO repositório no GitHub:

1. Crie um novo repositório vazio no seu GitHub com o nome:
   `painel-imobiliaria`

2. No terminal da sua máquina (dentro da pasta `painel-imobiliaria`), execute:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit painel administrativo imobiliaria"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO_GITHUB/painel-imobiliaria.git
   git push -u origin main
   ```

## 🌐 Como conectar na Vercel (Novo Projeto):

1. Acesse seu painel da [Vercel](https://vercel.com).
2. Clique em **"Add New..."** -> **"Project"**.
3. Selecione o NOVO repositório: `painel-imobiliaria`.
4. Mantenha as configurações padrão (Framework: Vite).
5. Clique em **"Deploy"**.

Pronto! Você terá:
- **Site Principal**: `https://lbnegociosimobiliarios-tru.vercel.app` (intacto e inalterado)
- **Painel Administrativo**: URL exclusiva da Vercel para gerenciar o catálogo.
Ambos compartilham o mesmo Firebase Firestore em tempo real!
